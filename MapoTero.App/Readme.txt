MapoTero - program do pobierania map rastrowych WMS, WMTS i XYZ/TMS
Strona projektu: https://github.com/Eksploracja/MapoTero
Podręcznik online: https://eksploracja.github.io/MapoTero/pomoc/
========================================================================

JAK URUCHOMIĆ PROGRAM:
1. Rozpakuj całe archiwum ZIP do wybranego folderu (np. C:\MapoTero).
2. Upewnij się, że folder "warstwy" znajduje się w tym samym katalogu
   co plik "MapoTero.exe" (bez niego lista map w programie będzie pusta).
3. Uruchom MapoTero.exe.
4. Na początek naciśnij Ctrl+K, aby uruchomić Szybki kreator map.

KOMUNIKAT SMARTSCREEN (PIERWSZE URUCHOMIENIE):
Program jest darmowy, bezpieczny i otwartoźródłowy, ale nie posiada płatnego
podpisu cyfrowego. Jeśli system wyświetli niebieski ekran
"System Windows ochronił ten komputer":
-> Kliknij odnośnik "Więcej informacji", a następnie przycisk "Uruchom mimo to".

WYMAGANIA SYSTEMOWE:
- System Windows (64-bitowy).
- Środowisko .NET Desktop Runtime 10 (x64). Jeśli nie jest zainstalowane,
  system zaproponuje jego pobranie przy pierwszym uruchomieniu.
