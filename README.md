# MapoTero

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/.NET-10-purple.svg)](https://dotnet.microsoft.com/)
[![Kompilacja i testy](https://github.com/Eksploracja/MapoTero/actions/workflows/kompilacja.yml/badge.svg)](https://github.com/Eksploracja/MapoTero/actions/workflows/kompilacja.yml)
[![Dokumentacja](https://img.shields.io/badge/Dokumentacja-GitHub%20Pages-brightgreen.svg)](https://eksploracja.github.io/MapoTero/pomoc/)
[![Facebook](https://img.shields.io/badge/Facebook-MapoTero-1877F2?logo=facebook&logoColor=white)](https://www.facebook.com/mapotero.opensource)

**MapoTero** to darmowy program służący do pobierania rastrowych map z internetu, opublikowanych za pośrednictwem serwerów WMS (takich jak Geoportal2, PIG, GDOŚ) oraz usług kafelkowych WMTS i XYZ/TMS (np. Waymarked Trails, OSMapa.pl, UMP-pcPL). 

Program pobiera mapy, dzieląc wybrany obszar na siatkę kwadratowych segmentów (do 2048×2048 px). Pobrane segmenty map można następnie:
* **scalić w jeden duży plik rastrowy** (GeoTIFF, JPEG, PNG) z georeferencją - format *Arkusz* w oknie *Eksport mapy* (*Narzędzia > Scalanie segmentów*),
* **wyeksportować do map dla odbiorników GPS i aplikacji mobilnych:** Garmin BirdsEye (JNX - wielopoziomowy raster bez limitu 100 kafli), Garmin Custom Maps (KMZ z wyborem z-order i obsługą przezroczystych nakładek PNG), MBTiles (Locus Map, OsmAnd, OruxMaps), OGC GeoPackage (QField, Mergin Maps, QGIS), SQLiteDB (OsmAnd, Locus Map) i mapy offline OruxMaps - także jako przezroczyste nakładki lub z kilkoma warstwami nałożonymi na siebie,
* **błyskawicznie przesłać na telefon przez Wi-Fi i kod QR:** bez kabli USB i bez zewnętrznej chmury – zeskanuj aparatem smartfona kod QR wyświetlony na ekranie po eksporcie, aby bezpośrednio pobrać mapę do telefonu,
* **wstawić do rysunku CAD** (AutoCAD, AutoCAD LT, BricsCAD, ZWCAD i inne): rysunek DXF z rastrami na właściwych współrzędnych, obrysem, siatką i numerami segmentów oraz skrypt SCR lub program LISP, które wstawiają mapę do otwartego rysunku,
* **wgrać do urządzeń GPS** i aplikacji turystycznych (np. [TrekBuddy](http://www.trekbuddy.net/forum/index.php), [OziExplorer](http://www.oziexplorer.com/)),
* **wyświetlić jako podkład georeferencyjny** w programach GIS i GPS: [QGIS](https://www.qgis.org/), [Google Earth](https://www.google.pl/intl/pl/earth/), ArcGIS, GPS Tuner, MapInfo.

* **Obsługiwane formaty rastrowe:** JPEG, TIFF, PNG, GIF; arkusze scalone: GeoTIFF, JPEG, PNG.
* **Obsługiwane formaty georeferencji:** MAP, KML, TAB, JPGW, WLD, GMI, PRJ.
* **Eksport do CAD:** rysunek DXF (R2000), skrypt SCR i program LISP (.lsp).
* **Układy współrzędnych:** PL-1992, PL-2000 (strefy 5-8), UTM (strefy 33N-35N), WGS84.
* **Podręcznik użytkownika online:** [eksploracja.github.io/MapoTero/pomoc/](https://eksploracja.github.io/MapoTero/pomoc/)
* **Oficjalny profil programu:** [facebook.com/mapotero.opensource](https://www.facebook.com/mapotero.opensource)

## Pobieranie i dokumentacja

Program to jeden plik **MapoTero.exe** (wersja 64-bitowa dla systemu Windows), dostarczany w paczce ZIP razem z folderem `warstwy` (zbiory map):
* 📥 **[Pobierz najnowszą wersję MapoTero z GitHub Releases (MapoTero_v3.18.zip)](https://github.com/Eksploracja/MapoTero/releases/download/v3.18/MapoTero_v3.18.zip)** – po rozpakowaniu uruchom `MapoTero.exe` (folder `warstwy` musi leżeć obok niego).
* 📖 **[Podręcznik użytkownika i pomoc online](https://eksploracja.github.io/MapoTero/pomoc/)** – 39 rozdziałów instrukcji krok po kroku z motywem Just the Docs, opis narzędzi, formatów i konfiguracji.
* 📦 Wszystkie wydania, kody źródłowe i historia wersji: **[GitHub Releases](https://github.com/Eksploracja/MapoTero/releases/latest)**.

> [!NOTE]
> **Pierwsze uruchomienie w systemie Windows (komunikat SmartScreen):**  
> Program jest w pełni bezpieczny i otwartoźródłowy (GPLv3), lecz nie posiada kosztownego komercyjnego certyfikatu podpisu cyfrowego. System Windows może przy pierwszym uruchomieniu wyświetlić niebieski monit *"System Windows ochronił ten komputer"*.  
> * **Jak uruchomić:** Kliknij odnośnik **„Więcej informacji”**, a następnie przycisk **„Uruchom mimo to”**.  
>
> ![Okno SmartScreen: najpierw „Więcej informacji”, potem „Uruchom mimo to”](obrazy/smartscreen.png)
>
> * **Wskazówka:** Możesz także przed rozpakowaniem kliknąć prawym przyciskiem myszy na pobranym pliku ZIP → **Właściwości** → zaznaczyć pole **„Odblokuj”** na dole i kliknąć **OK**.
> * **Jak sprawdzić plik:** w opisie każdego [wydania](https://github.com/Eksploracja/MapoTero/releases/latest) są sumy kontrolne SHA-256 archiwum ZIP i pliku `MapoTero.exe` oraz odnośnik do wyniku skanu programami antywirusowymi w serwisie VirusTotal.

## Aktualności

* **Okno główne:** **Nowa sesja** i **Folder pobrań** są nad mapą obok narzędzi obszaru i wyboru podkładu. Przyciski zoomu są w narożniku mapy, siatka w menu **Sesja pobierania**, a ustawienia w menu **Narzędzia**. Po skompletowaniu segmentów belka pod mapą pokazuje **Eksportuj pobraną mapę…**. Starsze lub niepełne sesje można otworzyć w eksporcie z menu **Narzędzia**. Panel warstw sięga do paska stanu. Zakładki **Podgląd**, **Komunikaty** i **Sesja** wypełniają jego szerokość. Podgląd pokazuje powiększenie próbki w procentach, a **Dopasuj** przywraca widok całej próbki.

* **Okno główne – czytelniejszy układ:** przycisk **Pobierz segmenty** stoi w karcie **Stan sesji** (bez osobnego, prawie pustego wiersza pod kartami); jest wyróżniony kolorem, gdy można pobierać, a bez warstwy lub obszaru jest przygaszony. Nad mapą jest pole **Szukaj miejsca lub działki…** z lupą – podpowiedzi miejscowości i adresów pojawiają się pod polem w trakcie pisania, strzałki zmieniają wybór, a Enter przesuwa mapę; działkę (np. „działka Wieliczka 123/4” albo identyfikator TERYT) pole szuka po Enter i ustawia wokół niej obszar pobierania, a wklejone współrzędne od razu przesuwają mapę (Ctrl+F przenosi kursor do pola). Przyciski **+** i **−** na mapie są większe i rozsunięte, a przybliżanie kółkiem myszy nie przenosi już kursora na środek mapy. Pasek nad mapą ma trzy grupy z równymi odstępami: **Nowa sesja** i **Szybki kreator…**, potem **Zaznacz obszar** z wyszukiwarką, a na końcu **Folder pobrań**. Lista wybranych warstw i zakładki z podglądem są wyższe; przyciski podglądu stoją w kolumnie obok próbki, a mikser warstw otwiera przycisk **Mikser…** w nagłówku karty wybranych warstw (albo kliknięcie próbki). Karty pod mapą mają ramki i wyraźne odstępy. Mikser warstw pokazuje podgląd bez korekty obrazu, dopóki jej nie włączysz. Okna, które wystawały poza dolną krawędź niskiego ekranu (np. szybki kreator), program przesuwa w górę przy otwarciu. Parametry segmentów rozwija odnośnik **Zmień…** w ich karcie, a odnośnik **Zmień ▾** w karcie obszaru otwiera menu: **Pokaż na mapie**, **Zaznacz na mapie**, **Wpisz współrzędne…** (dawniej przycisk **Współrzędne…** na pasku), **Obszar wzdłuż trasy (GPX, KML, KMZ)…** i **Obszar z poligonu (KML, GeoJSON)…**; kliknięcie wymiaru obszaru (np. „2 × 2 km”) też pokazuje go na mapie; wczytana sesja, której obszaru nie widać na mapie, pokazuje się przy starcie. W prawym dolnym rogu mapy jest podziałka. Panel warstw jest domyślnie szerszy, drzewo nie ma poziomego paska przewijania (pełną nazwę pokazuje podpowiedź), a przyciski **Zwiń/Rozwiń** i **+ Serwer…** mają napisy zamiast symboli. Sekcje panelu i zakładki mają ten sam styl co karty pod mapą, a podpowiedź „co dalej” jest już tylko w karcie stanu.

* **Okno główne – jeden styl kart, pasek stanu i krycie w liście warstw:** karty pod mapą mają ikony: przerywany prostokąt przy obszarze (ten sam co na przycisku **Zaznacz obszar**), siatkę przy parametrach segmentów i ikonę stanu sesji, która pokazuje strzałkę pobierania, łuk postępu w trakcie pobierania, zielony znak ✓ po pobraniu albo czerwony wykrzyknik przy błędach. Karty w prawym panelu mają ramki i nagłówek na przyciemnionym pasie z ikoną, tytułem i akcją karty (**+ Serwer…** w katalogu, **Mikser…** w wybranych warstwach), a zakładki **Podgląd**, **Komunikaty** i **Sesja** mają ikony; przy błędach zakładka komunikatów jest czerwona i pokazuje ich liczbę. Wysokość kart prawego panelu zmienia się przeciągnięciem uchwytu „═” między nimi (dwuklik przywraca podział domyślny); program zapamiętuje ją w `lastsettings.txt`. W liście wybranych warstw krycie zmienia się bezpośrednio w wierszu zaznaczonej warstwy, a krzyżyk ✕ na końcu wiersza usuwa warstwę; kolejność zmienia przeciągnięcie, Ctrl+↑/↓ lub menu prawego przycisku, a dopisek „↑ na wierzchu” w nagłówku przypomina, że górna warstwa leży na wierzchu. Dawny wiersz przycisków ▲ ▼ ✕ i pole **Krycie %** pod listą zniknęły. Pasek stanu ma sekcje: układ współrzędnych sesji, współrzędne kursora w tym układzie (X na północ, Y na wschód), przybliżoną skalę mapy na ekranie oraz po prawej nazwę sesji z kolorową kropką stanu – kliknięcie przy błędach otwiera zakładkę **Komunikaty**. Układ współrzędnych jest w karcie **Parametry segmentów** (np. „PL-1992 · bok 2000 px · JPEG”), bo tam się go zmienia. Menu **Sesja pobierania** ma polecenie **Obszar pobierania z poligonu (KML, GeoJSON)...** tuż pod obszarem wzdłuż trasy. Mikser warstw pojawia się od razu z napisem „Wczytywanie podglądu…”, a próbkę składa i pobiera dopiero po otwarciu okna. Tekst w polu wyszukiwania stoi na środku wysokości pola, w linii z napisami przycisków paska.

* **Obszar pobierania z pliku GeoPackage (.gpkg):** poligony i linie z warstwy wektorowej GeoPackage (np. granica gminy, działki albo trasa narysowana w QGIS) wyznaczają obszar pobierania tak jak pliki KML i GeoJSON. Plik wskażesz w poleceniach **Obszar pobierania z poligonu** i **Obszar pobierania wzdłuż trasy** (menu **Sesja pobierania** oraz **Zmień ▾** w karcie obszaru) albo przeciągniesz na mapę. Gdy plik ma kilka warstw, program pyta, której użyć. Poligony dają prostokąt obszaru z podglądem, a linie – obszar wzdłuż trasy. Obsługiwane układy warstwy: PL-1992, PL-2000, UTM 33–35N, WGS84 i Web Mercator; przy innym układzie program prosi o zapisanie warstwy w jednym z nich.

* **W przygotowaniu – poprawki z przeglądu programu:**
  * **Bezpośredni transfer map na telefon przez Wi-Fi i kod QR (menu Narzędzia i okna eksportu):** po wygenerowaniu mapy w oknie *Eksport mapy* (oraz z menu *Narzędzia > Prześlij mapę na telefon (Wi-Fi)...* i w szybkim kreatorze mapy) przycisk *Wyślij na telefon...* uruchamia wbudowany, lekki serwer w lokalnej sieci Wi-Fi i wyświetla na ekranie duży, czytelny kod QR wygenerowany bezpośrednio przez program (własny generator bez zewnętrznych bibliotek). Wystarczy skierować aparat smartfona na ekran komputera, aby otworzyć stronę pobierania i jednym kliknięciem pobrać plik `.mbtiles`, `.gpkg`, `.tif`, `.kmz`, `.sqlitedb` lub `.tar` prosto do pamięci urządzenia (Locus Map, QField, OsmAnd, OruxMaps, Avenza Maps) bez podłączania kabla USB i bez wysyłania plików do chmury; serwer obsługuje wznawianie przerwanych transferów (nagłówek HTTP Range), wybiera kartę Wi-Fi lub Ethernet przed kartami VPN i maszyn wirtualnych i zabezpiecza każdą sesję losowym tokenem kryptograficznym (przy pierwszym użyciu system Windows wyświetla jednorazowy alert Zapory Windows Defender z pytaniem o zezwolenie na ruch w sieci prywatnej – kliknięcie „Zezwalaj na dostęp” natychmiast odblokowuje transfer),
  * **Obsługa formatu OGC GeoPackage (.gpkg) dla kafelków rastrowych Web Mercator (EPSG:3857):** bezpośredni eksport oraz kompilacja wieloskalowa do otwartego formatu bazy danych OGC GeoPackage 1.3, obsługiwanego przez QGIS i mobilne aplikacje GIS (QField, Mergin Maps); szybki kreator mapy nie tworzy plików GeoPackage,
  * **Kafelkowany GeoTIFF (256×256) z wewnętrzną piramidą powiększeń:** eksport mapy i scalanie arkuszy GeoTIFF tworzy teraz pliki o architekturze Cloud-Optimized GeoTIFF z kafelkowaniem wewnętrznym 256×256 pikseli i łańcuchem podkatalogów pomniejszeń (IFD reduced images), dzięki czemu wielogigabajtowe arkusze otwierają się w aplikacjach mobilnych (Avenza Maps) i stacjonarnych (QGIS, ArcGIS) natychmiastowo, dekompresując z dysku tylko aktualnie wyświetlane fragmenty,
  * **Szybki kreator generowania map (Ctrl+K, przycisk z różdżką):** prowadzi krok po kroku przez przygotowanie gotowej mapy: wybór urządzenia (smartfon - MBTiles lub SQLiteDB, odbiornik Garmin - KMZ dla Custom Maps albo JNX dla BirdsEye, arkusz GeoTIFF do druku, podkład GeoTIFF dla CAD/GIS), wybór jednego z gotowych stylów z podglądem (turystyka piesza na mapie topograficznej GUGiK, góry z poziomicami OpenTopoMap także po czeskiej i słowackiej stronie, trasy rowerowe i MTB, dziedzictwo kulturowe - rzeźba terenu LiDAR z prześwitującą mapą topograficzną i zabytkami NID (zabytki nieruchome z rejestru i z ewidencji, rejestr i ewidencja stanowisk archeologicznych), mapy WIG 1918–1939 z Messtischblattami tam, gdzie brak arkuszy WIG 1:25 000, mapy niemieckie do 1945 - Messtischblatt i Karte des Deutschen Reiches, działki EGiB albo własne warstwy z okna głównego; suwaki krycia cieniowania, szlaków, mapy topograficznej i zabytków (krycie ustawione w oknie *Warstwy - zaawansowane* jest nadrzędne, suwak zmienia je proporcjonalnie), pola wyboru zabytków archeologicznych i nieruchomych w stylu dziedzictwa kulturowego, a przy mapach historycznych opis ograniczeń pokrycia arkuszami), wskazanie obszaru (miejscowość z promieniem, prostokąt na mapie albo pas wzdłuż trasy GPX/KML) - przed wyborem stylu, żeby podgląd stylu pokazywał teren użytkownika - i automatyczne pobranie oraz zapis pliku; korekta obrazu jest domyślnie wyłączona (pole *Korekta obrazu* i okno *Profil / Podgląd…* z przyciskiem *Resetuj korektę*); **mapy wieloskalowe**: turystyka piesza, góry z poziomicami, trasy rowerowe i MTB oraz oba style historyczne w formacie MBTiles przełączają się przy oddalaniu na mapy w mniejszej skali (np. mapa topograficzna 1:10 000 → 1:25 000 → 1:50 000 → 1:100 000 → przeglądowa, WIG 1:25 000 → 1:100 000 → 1:300 000) zamiast pokazywać pomniejszoną, nieczytelną mapę szczegółową - kreator pobiera każdą skalę osobno i sam dobiera zakresy powiększeń. W turystyce pieszej i górach z poziomicami pole *Ortofotomapa przy zbliżeniu* (krok 4, domyślnie wyłączone) dodaje na największym powiększeniu (zoom 17, piksel 0,75 m) zdjęcie lotnicze ze szlakami tam, gdzie mapa 1:10 000 byłaby już tylko powiększonymi pikselami - plik jest wtedy kilkakrotnie większy; styl górski łączy ortofotomapy Polski, Czech (nowy zbiór map `czechy_orto_wms` - WMS przezroczysty poza Czechami, bo kafle WMTS mają dziury przy granicy), Słowacji i Saksonii. Podgląd pokazuje obrys obszaru lub pas trasy i pozwala wybrać skalę do obejrzenia. Zmiana korekty lub krycia zachowuje plan skal. Po przerwanym zapisie lub brakach pobierania poprzednia wersja mapy pozostaje dostępna. Gotowa mapa zachowuje wybrany zasięg na każdym poziomie, a tło poza obszarem w MBTiles i SQLiteDB jest przezroczyste (okno *Ustawienia skal…* pozwala wyłączyć skalę, zmienić jej piksel, zakres powiększeń i warstwy), a podgląd stylu po oddaleniu pokazuje mapę w mniejszej skali; rozmiar piksela i zakres powiększeń kreator dobiera do rozdzielczości danych (z ostrzeżeniem, gdy mniejszy piksel nie doda szczegółów), szacuje rozmiar pliku i czas z uwzględnieniem liczby serwerów, ostrzega przed przekroczeniem limitu 100 kafli Garmin i brakiem miejsca na dysku, nie nadpisuje poprzednich map, zapisuje segmenty w folderze download, podczas pobierania pokazuje pozostały czas liczony z rzeczywistej prędkości pobierania i liczby segmentów wszystkich skal, po błędzie lub brakach pozwala ponowić pobieranie tylko brakujących fragmentów, a po zakończeniu podpowiada, gdzie skopiować plik w telefonie lub odbiorniku; opcje zaawansowane są zwinięte, a pasek kroków w dolnej części okna pozwala wrócić do dowolnego ukończonego kroku; w polu wyszukiwania obszaru można wkleić współrzędne punktu (WGS84 dziesiętnie lub w stopniach, minutach i sekundach, PL-1992, PL-2000) albo działkę (identyfikator TERYT lub „działka Wieliczka 123/4” - obszar to działka z pasem 150 m), a zamiast promienia wybrać prostokąt otaczający miejscowość (*wg granic*); przycisk *Profil…* pokazuje profil wysokościowy wczytanej trasy, a gdy obszar zaznaczono przed chwilą na mapie prawym przyciskiem myszy, kreator pomija krok wyboru obszaru, plik trasy można przeciągnąć na okno, podgląd obszaru mieści cały obszar z obrysem, a duży podgląd stylu w skali 1:1 pozwala ocenić czytelność napisów; własną kompozycję (warstwy, krycie, tryby mieszania, skale) można zapisać jako *mój styl* i wybierać z listy także po ponownym uruchomieniu; mapy wieloskalowe powstają też w formatach SQLiteDB (OsmAnd, Locus Map) i JNX dla odbiorników Garmin (BirdsEye); przy wydruku kreator podaje rozmiar arkusza i format papieru A, a gotową mapę otwiera przyciskiem *Otwórz mapę*,
  * **Tryb mieszania „7 Rzeźba terenu” dla cieniowania:** cieniowanie rzeźby terenu ma na płaskim terenie jasnoszary kolor (słońce 45° nad horyzontem), dlatego w trybie *Mnożenie* kładło na całą mapę szarą zasłonę, a przy małym kryciu rzeźby prawie nie było widać; nowy tryb traktuje ten szary jako neutralny - płaski teren zachowuje barwy mapy, stoki w cieniu ciemnieją, a oświetlone lekko jaśnieją; okno dodawania warstwy ustawia go dla cieniowania automatycznie (krycie 70%), a starsze wersje programu odczytują go jako tryb *Zwykły*,
  * **Polskie litery w ścieżkach przy angielskim formacie regionalnym:** przy formacie regionalnym innym niż polski (np. „angielski (USA)”) program zapisywał `lastsettings.txt`, `conf.txt` i pliki georeferencji w niewłaściwej stronie kodowej – ścieżka z polskimi literami (np. nazwa użytkownika Windows) zmieniała się z „Łukasz” na „Lukasz”, a po ponownym uruchomieniu program wczytywał inną sesję niż ostatnio używana; teraz pliki są zapisywane w stronie kodowej systemu, jak w dawnych wersjach,
  * **Komunikaty błędów po polsku:** typowe błędy (brak uprawnień, plik otwarty w innym programie, brak folderu, brak miejsca na dysku, przekroczony czas odpowiedzi serwera, uszkodzony obraz) są opisane po polsku ze wskazówką, co zrobić, zamiast angielskiej treści z .NET,
  * **Komunikaty przy uruchamianiu:** błąd odczytu `conf.txt` nie jest już zastępowany komunikatem „Wczytano ostatnio zapisane ustawienia”; program podaje ścieżkę uszkodzonego pliku, informuje o uszkodzonym `lastsettings.txt`, o braku folderu `warstwy` oraz o tym, że folder ostatniej sesji nie istnieje i wczytano inną sesję,

## Skrócona instrukcja obsługi

1. **Wybór mapy:** W drzewie *Wybierz mapy* po prawej stronie okna programu rozwiń (kliknięciem nazwy) grupę tematyczną i podgrupę z interesującą Cię mapą - np. *Mapy topograficzne > Skany map topograficznych GUGiK* (rozwinięte przy nowej sesji). Przycisk ⊞/⊟ rozwija lub zwija wszystkie zbiory, a pole *szukaj warstwy…* pokazuje tylko warstwy pasujące do wpisanych słów.
2. **Wybór warstwy:** Zaznacz pole wyboru interesującej Cię warstwy albo kliknij jej nazwę (np. *"1:25 000, układ 1965"* lub *"1:10 000, układ 1965"*); odznaczenie usuwa warstwę. Nazwa zaznaczonej warstwy wyświetli się w polu *"Wybrane warstwy oraz ich kolejność"* - pierwsza wybrana warstwa jest podkładem, kolejne kładą się na niej. Zaznaczoną tam warstwę (lub jedyną wybraną) usuniesz przyciskiem kosza albo ✕ (lub klawiszem Delete), przesuniesz przyciskami ▲ ▼ albo przeciągając ją myszą, a w polu *Krycie %* nadasz jej przezroczystość (np. 50% - widać przez nią warstwę leżącą niżej). Przycisk … otwiera okno z suwakami krycia i podglądem kanapki. Warstwy możesz brać z różnych zbiorów map (także WMS i WMTS razem): rozwiń inną grupę w drzewie i zaznacz jej warstwę - wybrane wcześniej warstwy zostają.
3. **Zaznaczenie obszaru:** Na podglądzie mapy zaznacz prawym przyciskiem myszy zasięg pobieranego obszaru albo wskaż plik trasy (*Sesja pobierania > obszar pobierania wzdłuż trasy*).
4. **Pobieranie:** Kliknij przycisk **"Pobierz"**. Rozpocznie się pobieranie segmentów do dedykowanego podfolderu sesji w katalogu `download` (np. `download/sesja_ortofotomapa_...`), dzięki czemu pliki nie zaśmiecają folderu nadrzędnego. Ponowne kliknięcie wznawia pobieranie w tym samym folderze i dociąga brakujące kafle.
5. **Przeglądanie i scalanie:**
   * Kliknij żółty folder, aby otworzyć katalog z pobranymi plikami bieżącej sesji.
   * Opcjonalnie scal pobrane segmenty w jeden arkusz ikoną szachownicy albo poleceniem *Narzędzia > Scalanie segmentów* – otworzy się okno *Eksport mapy* z formatem *Arkusz* (GeoTIFF, JPEG lub PNG). Arkusz zapisywany jest pasami, więc może mieć dowolną wielkość (JPEG - do 65 500 px na bok).
   * Opcjonalnie wyeksportuj mapę do JNX, KMZ, MBTiles, SQLiteDB, OruxMaps albo paczki TrekBuddy / Locus Map (*Narzędzia > Eksport mapy*), aby wgrać ją do odbiornika GPS lub aplikacji mobilnej.
   * Opcjonalnie wyeksportuj mapę do programu CAD (*Narzędzia > Eksport do CAD*): rysunek DXF otwórz w programie CAD, a skrypt SCR uruchom poleceniem `SCRIPT` w otwartym rysunku (jednostki: metry). Program LISP (AutoCAD, BricsCAD, ZWCAD, AutoCAD LT od wersji 2024) wczytaj poleceniem `APPLOAD` - wstawia też numery segmentów i opis, a po zakończeniu przywraca ustawienia rysunku. Oś X rysunku to wschód, oś Y - północ; mapa trafia na warstwy `MAPOTERO_...`. Przy setkach segmentów wygodniej wstawić scalony arkusz (GeoTIFF albo JPEG z plikiem world file) - przycisk *Scal segmenty...* w oknie eksportu do CAD.

## Obsługiwane serwery WMS i WMTS

* **Geoportal2** (Główny Urząd Geodezji i Kartografii)
* **Państwowy Instytut Geologiczny (PIG)**
* **Generalna Dyrekcja Ochrony Środowiska (GDOŚ)**
* **Narodowy Instytut Dziedzictwa (NID)** i **Instytut Historii PAN (IHPAN)**
* **Służby geodezyjne krajów sąsiednich:** Czechy (**ČÚZK**), Słowacja (**ZBGIS**, **Freemap**), Niemcy (**BKG**, **GeoBasis-BB Brandenburgia**, **GeoSN Saksonia**), Litwa (**INSPIRE**) oraz europejskie bazy morskie (**EMODnet Bathymetry**) i **OpenTopoMap**.

Zbiory map to pliki tekstowe w katalogu `warstwy`: w pierwszym wierszu adres serwera, dalej pary wierszy - nazwa warstwy i zalecany rozmiar piksela. Grupy drzewa *Wybierz mapy* i zrozumiałe nazwy warstw opisuje plik `warstwy/katalog.txt` (UTF-8): wiersz `> Grupa` otwiera grupę, `>> Podgrupa` - podgrupę, a wiersz `zbiór | warstwa | nazwa` dodaje do niej warstwę ze zbioru map; warstwy spoza katalogu program pokazuje w grupie *Dodane serwery*. Adres usługi WMTS (np. zawierający `SERVICE=WMTS` lub `/WMTS`) oznacza pobieranie kafli WMTS; nazwą warstwy jest wtedy identyfikator warstwy z dokumentu GetCapabilities usługi.

### Wskazówki dla map w strefie przygranicznej

* **Dobór układu współrzędnych:**
  * **Warstwy WMTS i XYZ** (np. czeska *ZTM_WM*, słowacka *Freemap Outdoor*, niemiecka *basemap.de*, *OpenTopoMap*): działają bez problemu w każdym układzie (PL-1992, PL-2000, UTM, WGS84) – program przelicza je w locie na siatkę wybranego układu.
  * **Warstwy czystego WMS** (szczegółowe skany czeskie *ZTM 10/25/50*, słowackie *ZM10/25/50*, brandenburskie *DTK10/25/50*): serwery te nie obsługują polskiego układu PL-1992. W oknie głównym MapoTero wybierz dla nich układ **WGS84 (EPSG:4326)** lub strefę **UTM 33N/34N** (wspólne dla Polski i sąsiadów; Saksonia dodatkowo wspiera bezpośrednio PL-1992).
* **Nakładanie map i przezroczystość (łączenie bez białych plam):**
  * Jeśli tworzysz kompozycję z polskiego podkładu i warstwy zagranicznej, a serwer zagraniczny wypełnia obszar poza swoją granicą białym kolorem zamiast przezroczystości (np. Saksonia lub Brandenburgia), w oknie *Warstwy zaawansowane* (przycisk `…`) zmień tryb mieszania górnej warstwy na **Mnożenie (Multiply)**. W tym trybie biel staje się niewidoczna, a treść obu map (drogi, warstwice, napisy) łączy się idealnie na granicy.

## Kompilacja

* Wymagany Visual Studio 2026 (wersja 18.0 lub nowsza) z obsługą .NET 10 albo samo .NET 10 SDK (Visual Studio 2022 nie kompiluje projektów .NET 10).
* Kod źródłowy: `MapoTero.App` - program (okna Windows Forms), `MapoTero.Core` - obliczenia i formaty plików, `MapoTero.Tests` - testy jednostkowe, `warstwy` - zbiory map; w Visual Studio otwórz `MapoTero.sln`.
* **Program wydawany jest wyłącznie jako jeden plik `MapoTero.exe`.** Tworzy go polecenie
  `dotnet publish MapoTero.App/MapoTero_v3.vbproj -c Release -o MapoTero_SingleFile` - w folderze `MapoTero_SingleFile` powstaje `MapoTero.exe`
  z folderem `warstwy` i plikiem `README.md`. Projekt nie pozwala opublikować wersji wieloplikowej.
* Kompilacja do sprawdzenia kodu: `dotnet build MapoTero.App/MapoTero_v3.vbproj -c Release` (folder `bin` zawiera tylko pliki pośrednie kompilacji),
  testy jednostkowe: `dotnet test MapoTero.Tests/MapoTero.Tests.vbproj -c Release`.
* Każda zmiana w repozytorium jest kompilowana i testowana w GitHub Actions; gotowy program (`MapoTero.exe` z folderem `warstwy`)
  można pobrać jako artefakt *MapoTero* z zakładki **Actions**.
* Do uruchomienia programu potrzebne jest środowisko [.NET Desktop Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0) (x64).
